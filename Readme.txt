Student Management System (MERN Stack)
A Full Stack Student Management System built using MERN Stack:
* MongoDB – NoSQL Database for storing student data
* Express.js – Backend API framework for handling requests
* React.js – Frontend UI for managing students
* Node.js – JavaScript runtime for the backend
Features
* Add, Edit, Delete, and View Students
* API-based CRUD Operations
* Fully Responsive UI
* MongoDB Integration
Installation Steps
1. Clone the Repository
git clone https://github.com/Kondakavuri-Pavani/Student-Management-System.git 
cd Student-Management-System
2. Setup Backend
cd backend
npm install
npm start
3. setup Frontend
cd ../frontend
npm install
npm start

4. Open in Browser
Backend: http://localhost:5000
Frontend: http://localhost:3000



API Endpoints (Backend)
MethodEndpointDescriptionPOST/api/students/add

GET/api/students

PUT/api/students/:idUpdate student
DELETE/api/students/:idDelete student
