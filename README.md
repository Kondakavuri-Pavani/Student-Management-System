# Student Management System (MERN Stack)

A Full Stack **Student Management System** built using **MERN Stack**:

- **MongoDB** – NoSQL Database for storing student data
- **Express.js** – Backend API framework for handling requests
- **React.js** – Frontend UI for managing students
- **Node.js** – JavaScript runtime for the backend

##  Features
- Add, Edit, Delete, and View Students  
- API-based CRUD Operations  
- Fully Responsive UI  
- MongoDB Integration  

##  Requirements

Before running this project, ensure you have the following installed:

1. **Node.js** (>= 14.x) – [Download & Install](https://nodejs.org/)
2. **MongoDB** (>= 5.x) – [Download & Install](https://www.mongodb.com/try/download/community)
   - Alternatively, use **MongoDB Atlas** (Cloud Database) with a valid connection string.
3. **Git** (Optional, for cloning the repository) – [Download & Install](https://git-scm.com/)
4. **Postman or cURL** (Optional, for testing APIs)
5. **A Code Editor** (VS Code recommended) – [Download & Install](https://code.visualstudio.com/)
